# Web 3D Tech — Landing Page

Landing page e-commerce untuk brand **Web 3D Tech** — perangkat tech personal dengan estetika modern, sleek, dan minimalis.

## 📂 Struktur

```
3d-website-tech/
├── index.html      # Landing page lengkap (single file)
└── README.md       # File ini
```

## 🎨 Design Direction

| Aspek | Value |
|-------|-------|
| Brand | **Web 3D Tech** (W3D) |
| Niche | Tech / Gadget |
| Tone | Modern, sleek, minimalis |
| Color palette | Hitam (#0A0A0A) · Bone (#F5F4EF) · Accent lime (#C7FF3D) · Muted (#8B8B85) |
| Typography | Space Grotesk (display) + JetBrains Mono (label) |
| Stack | Tailwind CDN + Alpine.js + Lucide Icons |

## 🧩 Sections

1. **Sticky Nav** dengan cart counter (Alpine.js reactive)
2. **Hero** — Headline besar, animated background blobs, featured product card dengan glow ring
3. **Marquee** — Infinite scroll tagline strip
4. **Product Grid** — 6 produk dengan hover effect
5. **Story Section** — Dark inverted section
6. **Specs Grid** — 4 spec tiles
7. **CTA + Newsletter** — Yellow accent section
8. **Footer** — 4-column dengan social links

## 🚀 Cara Menjalankan

```bash
open index.html
# atau
python3 -m http.server 8000
```

## ✨ Fitur

- ⚡ **Fully interactive** — cart counter, hover effects
- 🎞️ **Animated** — drift blobs, marquee, grain noise overlay
- 📱 **Responsive** — mobile-first grid
- 🎯 **No build step** — buka langsung di browser
